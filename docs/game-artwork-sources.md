# Game artwork sources

Artwork files in `public/images/games/` are locally optimized WebP copies. They are used as catalog thumbnails; each game publisher retains its own trademarks and image rights.

| File                  | Source                                                                                                                                                         |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `roblox.webp`         | [Roblox on Google Play](https://play.google.com/store/apps/details?id=com.roblox.client)                                                                       |
| `mobile-legends.webp` | [Mobile Legends official site](https://www.mobilelegends.com/gallery), image from `akmweb.youngjoygame.com/web/gms/image/c3d1596795b86dc26e5f1ef2d48c3dfd.jpg` |
| `free-fire.webp`      | [Free Fire on Google Play](https://play.google.com/store/apps/details?id=com.dts.freefireth)                                                                   |
| `pubg-mobile.webp`    | [PUBG Mobile on Google Play](https://play.google.com/store/apps/details?id=com.tencent.ig)                                                                     |
| `valorant.webp`       | [VALORANT Media](https://playvalorant.com/en-us/media/), Episode 7 Act III key art package                                                                     |
| `genshin-impact.webp` | [Genshin Impact on Google Play](https://play.google.com/store/apps/details?id=com.miHoYo.GenshinImpact)                                                        |

The Google Play images are the artwork shown in the official publisher listings. Riot's media page allows its media assets for press and creator use and refers users to Riot's legal guidelines. Review each publisher's current terms before reusing these assets outside this project.
